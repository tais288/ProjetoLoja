# Projeto Loja

Sistema de gerenciamento de uma loja desenvolvido em ASP.NET Core MVC.

## Tecnologias utilizadas

- C#
- ASP.NET Core MVC
- .NET 9
- Entity Framework Core
- SQLite
- Repository Pattern

## Funcionalidades

O sistema possui três CRUDs:

- Clientes
- Produtos
- Pedidos

Cada cadastro permite realizar as operações de:

- Cadastrar
- Visualizar
- Editar
- Excluir
